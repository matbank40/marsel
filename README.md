# MARSEL — сайт фотографа

Портфолио и онлайн-запись на съёмку.

## Что внутри

- **Вступительный ролик** (Three.js): камера Polaroid (public/models/polaroid.obj) прилетает, делает снимок со вспышкой,
  наклоняется — из щели выезжает фото, проявляется, летит в экран
  и становится первым экраном сайта.
  Ролик можно пропустить; при `prefers-reduced-motion` он не показывается, а 3D-движок
  даже не загружается. После ролика WebGL выгружается.
- **Шрифты:** Oswald (заголовки) и Inter (текст).
- **Карусель «Избранные работы»** — 3D-кольцо, крутится скроллом и пальцем.
- **Галерея с фильтрами** и полноэкранный просмотр со свайпами.
- **Коллажи** — горизонтальная лента.
- **Пакеты** Silver Chariot и Gold Experience, **форма записи** с календарём.

Снимок для ролика и первого экрана задаётся константой `HERO_PHOTO` в `src/main.js`.

## Запуск

```bash
npm install
npm run dev
```

Сборка: `npm run build` (результат в `dist/`).

## Публикация на GitHub Pages

Workflow `.github/workflows/pages.yml` собирает сайт и выкладывает его при каждом пуше.
Один раз включите Pages: **Settings → Pages → Build and deployment → Source: GitHub Actions**.
Адрес сайта: https://matbank40.github.io/marsel/

GitHub Pages — статический хостинг: на нём нет серверной части, поэтому токен бота туда
класть нельзя (его увидит любой посетитель). На Pages форма открывает Telegram
с уже набранной заявкой. Чтобы заявки приходили автоматически, используйте Vercel (ниже).

## Публикация на Vercel

1. Импортируйте репозиторий на vercel.com — фреймворк Vite определится сам.
2. В **Settings → Environment Variables** добавьте:
   - `TELEGRAM_BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather);
   - `TELEGRAM_CHAT_ID` — ваш chat id (напишите боту [@userinfobot](https://t.me/userinfobot)).
3. Напишите своему боту `/start`, чтобы он мог присылать вам сообщения.

Функция `api/booking.js` пересылает заявки в Telegram. Если переменные не заданы
или сайт открыт не на Vercel, форма предложит отправить заявку через Telegram
с уже набранным текстом — ни одна заявка не потеряется.

## Как добавить фото

1. Сконвертируйте фото в WebP (полный размер + превью):
   ```bash
   python3 scripts/optimize_photos.py путь/к/фото.jpg имя-фото
   ```
2. Добавьте запись в `photos` (или `collages`) в `src/data.js`:
   ```js
   { id: 'имя-фото', title: 'Название', cat: 'portrait', w: 1333, h: 2000, alt: 'Описание' },
   ```
   Категории: `portrait`, `fashion`, `editorial`, `couple`, `concert`.

Цены, состав пакетов и контакты — тоже в `src/data.js`.
